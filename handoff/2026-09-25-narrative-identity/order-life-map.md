# order.life repo map — surveyed 2026-09-25

Read-only survey of the `order.life` submodule (master, last commit 2026-09-06), made on her request
to "sort out roughly what's on the order.life repo". Nothing in it was changed.

- **Size:** 1,604 commits, 175,216 tracked files, ~1.7 GB working tree, 510 MB pack. `wikibase/` is
  1.7 GB of it (164,573 Wikidata-format item JSONs, 4,840 wiki pages, 377 images, analysis TSVs).
- **The Gaiad:** `Gaiad/epic/chapter_NNN.md`, chapters 001–252 plus 329 of 364 planned (13 months ×
  28 days). Inline tags `{{c|Name}}`, `{{p|Place}}`. Month compilations in `Gaiad/epic/compiled/`,
  root `gaiad_full*.md`, generated by `scripts/compile_gaiad.py` via `compile-gaiad.yml`. **Leo =
  ch. 225–252 = the Book of Lehi** (Americas). Separate prose book: `Gaiad/religion-book/`.
- **Genealogy, two systems:** (1) small — `Gaiad/genealogy/*.json`, 2,044 characters, rendered by
  `build.py` → `/en/gaiad/characters/{slug}/`; (2) large — the Wikibase dump, ~106,876 persons /
  128,414 edges in `wikibase/analysis/*.tsv`, exported to GEDCOM 5.5.1 at `/gedcom/gaiad.ged` by
  `wiki-scripts/export_gedcom.py`; per-person pages on the Miraheze wiki, not the static site; repair
  tooling in `wiki-scripts/` (`apply_*`, `cut_edges.py`, `merge_cluster.py`).
- **Build:** `build.py` (Python + Jinja2) → `site/`, 9 languages, iCal, RSS, GEDCOM; `deploy.yml` to
  GitHub Pages on push and daily 16:00 UTC; also `discord-bot.yml` (3-hourly state commits),
  `dotnet-build.yml` (`calendar-lib`).
- **Cruft:** `wiki-pages/` vs `wikibase/pages/` share 884 filenames; 16–19 MB images; 26 MB committed
  cache; saved chat HTML with big JS bundles; committed generated scripture; old XML/GEDCOM exports and
  .NET build output still in history; stale README (says 63 chapters).
- **Activity, last 3 months:** wikibase 130 commits, wiki-scripts 101, discord-bot 74, Gaiad 4.

**For the genealogy move** (her instruction, queued in ontology-harness): the large Wikibase persons
system and its `wiki-scripts/` are what goes to the genealogy project; the small character pages sit
with the epic. *My reading, confidence medium.*

## HER VERDICTS, 2026-09-25 — these outrank the audit above
